NOTE ON ORIGINAL / PROPRIETARY ALGORITHMS — NO THIRD-PARTY CODE
================================================================================

The following components are implemented entirely in original code using only
Python standard library functions (math, statistics). No third-party machine
learning framework, statistics library, or Bayesian inference package was used.

BAYESIAN BIOMARKER INFERENCE MODEL  (engine/tracking/bayes.py, genetics.py)
-----------------------------------------------------------------------------
The longitudinal biomarker tracking system implements a custom Normal-Normal
conjugate Bayesian inference pipeline with the following original components:

1. Genetic Prior Derivation
   Per-patient prior on theta (fractional biomarker change from baseline) is
   derived from the patient's genotype at 25 curated pharmacogenomically
   relevant SNPs. Each SNP carries per-peptide effect weights scaled by
   allele dosage (0/1/2 under Hardy-Weinberg equilibrium). The aggregate
   weight g drives a tanh-compressed responder strength r ~ Normal(1 +
   0.72*tanh(g), sigma_r), which then scales the panel's documented expected
   percent change to produce a biomarker-specific Gaussian prior.

2. Joint Bayesian Linear Regression (joint_fit_likelihood)
   Given a set of timestamped measurements (week, value), the model jointly
   estimates the pre-treatment baseline b and the effect-size parameter theta
   via a reparameterized linear model: y_i = b + phi*a(w_i) + epsilon_i,
   where phi = b*theta and a(w) = 1 - exp(-w/tau) is the peptide's
   exponential approach curve. An informative Normal prior is placed on b
   using the panel's documented physiologic baseline; phi has a weak prior.
   The posterior precision matrix is solved in closed form (2x2 Bayesian
   linear regression), iterating up to 4 rounds to refine the noise variance
   sigma^2 from residuals. The parameter theta is recovered from phi/b using
   the delta method. A Student-t inflation correction is applied to the
   posterior standard deviation to prevent under-coverage at small sample
   sizes (correction tabulated for df = 1..30).

3. Fallback Estimator (effective_observation)
   When the joint fit is not preferred, an inverse-variance pooling estimator
   converts each (week, value) pair to a theta estimate via
   theta_hat_i = (y_i/baseline - 1) / a(w_i) and combines them using
   precision-weighted averaging.

4. Normal-Normal Conjugate Update (update)
   Prior and likelihood are combined: tau_post = tau_prior + tau_like,
   mu_post = (tau_prior*mu_prior + tau_like*mu_like) / tau_post,
   producing a closed-form Gaussian posterior on theta.

5. Posterior Predictive Trajectory (predictive_curve)
   The posterior is projected through the approach curve to produce a mean
   trajectory V(w) = baseline*(1 + mu_post*a(w)) with a 95% credible band
   that propagates both theta uncertainty and baseline uncertainty when no
   pre-treatment sample is available.

6. Expected Change Window (expected_window)
   The posterior-informed expected detection window is derived analytically:
   weeks_min is when the predicted |delta/baseline| first exceeds one
   measurement-noise standard deviation; weeks_max is the 95%-plateau week
   (~3*tau). If the 95% credible interval includes zero, the direction is
   reported as inconclusive.

PHARMACOGENOMIC HGNN ENSEMBLE  (engine/pgx/hgnn.py, conformal.py)
-------------------------------------------------------------------
The hypergraph neural network (HGNN) drug-response predictor and Mondrian
conformal prediction calibrator are implemented in original Python code.
No third-party neural network framework (TensorFlow, PyTorch, scikit-learn)
is used. The conformal prediction layer applies Mondrian split conformal
sets using the Venn-ABERS / standard quantile approach implemented entirely
in original Python.
