# Paper logical reconstruction (lab jail)

One-paper semantic producer. Admit into instance `data/logic.jsonl` via `lit-review`.

Recipe: `references/include-what.md`. Design matrices stay in `paper-experimental-design`.

For each panel: purpose, meaning, methods used, evidenced result, locators. Point design at experiment IDs.

For each Methods procedure: identity, operations, parameters as stated, IO, what it produced, locators.

Public OA / customer-inbox PDFs only. No partner-lab trees. No invented PMID/DOI.
